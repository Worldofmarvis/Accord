# Accord seller dashboard visual refresh

This update refreshes the seller dashboard presentation while preserving the existing React components, API calls, routes, form validation, negotiation polling, listing edit lock, and sales-history behavior.

## Visual changes
- Updated shared design tokens to a cleaner PayPal-inspired blue/navy palette with cooler neutral surfaces.
- Refined the Accord top bar, navigation states, content width, cards, buttons, and form controls.
- Reworked seller dashboard spacing into a responsive two-column workspace: listing form on the left, negotiations and listings on the right.
- Improved active-negotiation notice, privacy note, listing rows, status badges, and mobile stacking.

## Important
No demo sales, earnings, ratings, chart data, or backend features were added. The dashboard continues to render data from the existing application APIs.
